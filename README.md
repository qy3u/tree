# Tree · 本地笔记

使用 MyGo 原生 UI、原生富文本编辑器和 SQLite 实现的简易桌面笔记软件。界面以白色正文、浅灰侧栏和父子页面为主。当前构建面向 macOS Apple Silicon。

## 设计文档

- [Git 友好序列化方案与格式说明](docs/git-serialization-design.md)：已实现 v1 及 Leaf 的 v2 扩展，包含按页面和 Block 拆分的确定性文本格式、按日计时记录、二进制附件及数据库还原约束，供 private GitHub 仓库通过 diff 保存变化。

- [Leaf 设计与操作](docs/leaf-design.md)：页面内独立的知识单元，支持先创建再填写、原位编辑与自动开头预览。

## 运行

直接打开 `build/darwin-arm64/Tree.app`。

开发环境需要 Go 1.27.3 或更高版本。MyGo 与 CLI 固定为 v0.7.4：

```sh
go tool mygo dev
```

构建本机应用：

```sh
go tool mygo build -skip-dmg
```

首次开发或构建需要下载 Go 依赖及 SQLite 库。生成的 `.app` 已包含 SQLite，日常使用无需联网。当前为本机签名构建，未进行 Apple 公证。

应用图标采用选定的绿树方案。`assets/AppIcon.icon` 为 macOS 原生图标资源，由 MyGo 调用 Xcode 26 或更新版本编译为 `Assets.car`，同时生成旧版系统使用的 `.icns`。原图保存在 `assets/app-icon.png`；图层铺满系统图标边界，避免旧式图标在 Dock 中出现双层底框。构建时应确认输出包含 `Compiled AppIcon.icon`。

## 已实现

- 标签页：多页面打开与切换、拖动排序、独立前进／后退历史、关闭、横向滚动和重启恢复。
- 页面：新建、直接编辑标题、彩色页面图标、创建子页面、面包屑导航、拖动到父页面、侧栏上下排序、回收站恢复。
- 编辑：六级标题、段落、粗体、斜体、删除线、行内代码、项目列表、编号列表、待办、引用、代码块和链接。
- Leaf：`/leaf` 创建独立知识单元，标题与内容原位编辑，收起显示正文开头，整体移动、复制、删除与撤销。
- 内容：本地图片、剪贴板图片、分隔线，以及保留行列结构的简单表格。
- 操作：Markdown 快捷输入、`/` 插入菜单、选中文字后的浮动格式栏、悬停段落手柄、拖动与上下移动、撤销和重做。
- 保存：停止编辑约 450 毫秒后自动保存，切换页面和退出前保存；保存失败时保留窗口中的草稿并显示错误。
- 搜索：按标题和正文查找页面，包含当前表格内容以及 Leaf 标题和正文。
- 块引用：复制块链接、粘贴为可读引用，点击打开目标页面并定位、高亮对应内容块。
- 导出：当前页面及其子页面导出为 Markdown，包含 GFM 表格、子页面链接和本地图片。

## 基本操作

顶部「＋」或 ⌘T 打开页面选择浮窗：顶部搜索标题、路径和正文，左侧提供「创建新页面」及按访问时间分组的页面，右侧预览所选页面。点击或按 Enter 后才打开新标签页；↑↓ 选择，Esc 或点击浮窗外取消，取消不会创建标签或改变当前页面。创建新页面后光标进入标题。访问时间保存在本地，未访问页面列在「其他页面」。侧栏页面右键菜单、页面菜单中的「在新标签页中打开」，或 ⌘ 点击侧栏页面，可直接在新标签页打开笔记。左侧箭头只浏览当前标签页的历史；跳转到新页面会清除该标签页原有的前进历史。

点击标签切换，点击 × 或 ⌘W 关闭；Control+Tab / Control+Shift+Tab 切换到下一个／上一个标签页。仅剩一个标签页时仍显示 ×，点击 × 或按 ⌘W 会先保存再隐藏到后台，保留当前标签页和编辑状态。点击窗口红色关闭按钮或按 ⇧⌘W 也会隐藏到后台；保存失败则保留窗口。按 ⌘, 可重新呼出，⌘Q 才会真正退出程序。标题修改会同步显示在标签上。标签页过多时横向滚动，重启恢复标签与历史。同一页面在多个标签中共用正文和撤销状态。

[顶部标签栏的原生渲染预览](docs/tabs-preview.png)

点击左侧「新建页面」创建顶层页面；侧栏页面旁的「＋」、右键菜单、正文 `/page` 或 ⇧⌘N 创建子页面。父页面标题下显示子页面入口。直接修改大标题即可重命名，侧栏菜单也提供重命名入口。标题输入完成后按 Enter，光标进入正文开头，可直接继续输入。

侧栏页面支持「•••」菜单及右键菜单，可新建子页面、重命名、移动或删除；删除后进入回收站。将页面拖到另一行中间会成为其子页面；拖到行的上沿或下沿会显示蓝色落点线，放开后排在该页之前或之后；拖到侧栏「页面」标题处可移至顶层。右上角「•••」提供移动、同层排序、导出和删除页面，也显示保存状态和字符数。

正文采用居中的最大 720 DIP 内容列，白色背景、浅灰侧栏，标题和正文左边缘对齐。小窗口自动缩减两侧及顶部留白。标题、子页面入口、表格和正文共用页面滚动。格式栏在选中文字时浮出，光标收起选区后消失；自动保存不在顶部显示提醒，保存详情可在页面菜单中查看；失败时显示错误。

[当前界面的真实窗口截图](docs/notion-alignment.png)

在正文输入 `# `、`## `、`- `、`1. `、`> ` 等标记即可触发 Markdown 快捷格式。行内可输入 `**粗体**`、`*斜体*` 和反引号代码。

在段落开头或空格后输入 `/`，命令菜单会出现在当前段落旁边。继续输入关键词即可实时筛选，例如 `/todo`、`/待办`、`/checkbox` 都能找到待办列表；`/heading` 查找标题，`/code` 查找代码块，`/table` 打开表格编辑。支持中英文、不区分大小写。`↑↓` 选择，`Enter` 或 `Tab` 确认，也可点击结果；执行后整段命令文字会被替换为相应内容块。`Esc` 取消并保留输入，退格会同步更新结果。代码块、URL 和路径中的斜杠不会触发命令菜单。

输入 `/leaf` 创建知识单元，先填写标题，再按 Enter 编写内容。点击标题左侧箭头收起或展开；收起时自动预览正文开头。Leaf 的左侧抓手用于整体移动，菜单可复制或删除整个 Leaf。 点击左上角叶子图标可锁定标题与内容，图标变绿；再次点击恢复编辑。锁定后仍可展开、折叠和阅读，锁定状态随本地数据及 Git 备份保存。

斜杠菜单按内容类型分组，使用图标、名称和右侧淡色 Markdown 标记；底部「关闭菜单」与 Esc 一样保留已输入的文字。

右上角「＋」也提供可搜索的内容菜单。表格或图片选择取消时，原命令文字保留。文本、列表、标题、表格和分隔线命令的替换可以一次撤销。

[斜杠搜索的真实窗口截图](docs/slash-menu.png)

输入和换行时，左侧六点手柄跟随光标所在段落；移动鼠标后，手柄跟随悬停段落。拖动手柄到另一段落可调整顺序，点击手柄可在块前后插入、复制块、删除块、转换类型或上下移动。这些正文操作支持撤销。Enter 新建段落，Shift+Enter 在块内换行；Tab / Shift+Tab 调整普通段落和列表缩进，代码块内 Tab 插入制表符。

表格插入后可直接在正文中编辑单元格，Tab 切换单元格，底部按钮增减行列；第一行是表头，最多 30 行、6 列。修改单元格和结构支持撤销。插入菜单中的原生表单仍可用于初始设置和整表编辑。

公式在普通正文和 Leaf 内均可使用：粘贴独立的 `\[...\]` 或 `$$...$$`（支持多行）会显示为公式块；直接输入完整公式后按 Enter 也可转换。`/math` 创建公式块，点击已有公式编辑原始 LaTeX 并实时预览。编辑框内 Enter 换行，⌘Enter 或「完成」保存，Esc 取消；点击外部保存。支持撤销、重做、富文本复制及 Markdown 导入导出，数据库和 Git 备份保留原始 LaTeX。使用 Untie 原生排版和内置 New Computer Modern Math 字体，可离线使用；代码块和粘贴为纯文本保留源码。行内公式使用 `\(...\)` 或 `$...$`，输入闭合符号或粘贴后自动转换，随文字换行并对齐基线；正文及 Leaf 均可点击编辑原始 LaTeX。行内公式的复制、删除、撤销及 Markdown / Git 备份保留其行内形式。代码和转义符号不会触发转换，普通金额（例如 `$20 and $30`）保持文字。

图片通过「图片…」插入，也可在普通正文或 Leaf 内直接 ⌘V 粘贴剪贴板截图（PNG / macOS TIFF）。图片插入当前位置，保留前后文字，支持撤销和重做。点击图片选中后可删除；右键菜单调整为 240 / 400 / 560 的显示宽度，保持比例。图片导入时复制到应用附件目录。

搜索窗口采用单栏浮窗：无边框搜索栏、页面图标、同行灰色父页面路径与浅灰选中背景，不设右侧预览或底部提示栏。空搜索按最近访问时间分组；输入后搜索标题、路径和正文，正文命中且标题未命中时显示一行摘要。↑↓ 选择、Enter 打开当前标签页、Esc 或点击外部关闭。打开结果会选中正文中的匹配文字；表格内容匹配会定位到对应表格。

[搜索窗口原生渲染预览](docs/search-dialog-1120.png) · [小窗口预览](docs/search-dialog-850.png)

粘贴单个 HTTP/HTTPS 网址后，会显示「Paste as」浮层：选择「Plain Text」保留普通文字，选择「URL」保留可点击链接。默认以 URL 粘贴，Esc 或点击外部保留当前结果；支持上下键选择、Enter 确认。普通正文与 Leaf 均支持，代码块与粘贴为纯文本不弹出菜单。

## 本地数据

macOS 默认目录：`~/Library/Application Support/Tree Notes/`。

- `notes.db`：页面树、结构化正文、表格、设置与附件记录。
- `assets/`：导入的图片。
- `notes.db-wal`、`notes.db-shm`：SQLite 运行时文件。

正文 JSON 是原始数据，Markdown 是导出格式。导出总会创建一个新目录，不覆盖已有文件。侧栏底部「导入与备份」支持导入 Markdown、备份全部笔记、从备份导入。备份包含页面层级、回收站内容及本地附件；从备份导入会新建一组页面，保留现有笔记。也可以退出应用后复制整个数据目录。删除的页面只进入回收站；首版没有永久清空和附件自动回收。

开发或测试可以指定独立目录：

```sh
TREE_NOTES_DATA_DIR=/tmp/tree-notes-dev go tool mygo dev
```

每个页面在当前进程内保留自己的选区和撤销历史；重启恢复内容与最近打开的页面，撤销历史不跨进程保存。

## Git 文本快照

「导入与备份」→「导出 Git 文本快照…」会在所选目录内创建或更新 `tree-data/`。页面元数据、Block 内容、正文顺序、有效计时记录和设置分别写入 JSON / JSONL，图片保持原始二进制。无变化的重复导出不改写文件；旧表格和撤销用的旧计时版本不导出。

「从文本快照还原到新笔记库…」将完整数据还原到所选空目录，保留页面、Block、附件及笔记库 ID。还原不会覆盖或合并当前笔记库。也可以通过命令行导出、还原和打开新笔记库：

```sh
# 导出已保存的数据到仓库中的专用子目录，不启动编辑窗口
./build/darwin-arm64/Tree.app/Contents/MacOS/Tree --export-git /path/to/repository/tree-data

# 还原到不存在或为空的目录，其父目录必须存在
./build/darwin-arm64/Tree.app/Contents/MacOS/Tree --restore-git /path/to/repository/tree-data --data-dir /path/to/restored-library

# 打开还原后的笔记库
./build/darwin-arm64/Tree.app/Contents/MacOS/Tree --data-dir /path/to/restored-library
```

`--data-dir` 可指定导出的源笔记库，未指定时沿用 `TREE_NOTES_DATA_DIR` 或默认本地目录。命令行导出读取已落库的数据；应用内导出会先保存当前草稿。导出目标必须是专用空目录或同一笔记库的有效文本快照，不应直接选择 Git 仓库根目录。格式不支持、附件缺失、计时不一致或目标目录不适合时会报错并保留原数据。

运行中的计时只保存起点和此前累计值，不因导出而暂停或结算。还原仍保留运行状态，之后打开应用会按原起点继续计时。此功能只负责文本序列化和还原，不执行 Git 提交或推送。

## 代码高亮与代码块控件

复用 MyGo v0.7.4 `ui/editor` 的内置语言分词器，在原生富文本代码块中显示语法颜色。代码块右上角提供可搜索的语言选择与复制按钮；支持 Rust、Go、Python、JavaScript、TypeScript、Java、C/C++、C#、Swift、Kotlin、Ruby、PHP、Shell、SQL、JSON、HTML、CSS、YAML 等内置语言，也可选「纯文本」。复制保留缩进与真实换行，只包含当前代码块正文。

`/code` 默认创建纯文本代码块，可用右上角菜单指定语言；输入带语言的代码围栏（如三个反引号后接 rust）再按 Enter，也可创建指定语言的代码块。语言设置可撤销并随页面保存，Markdown 导入和导出保留围栏语言。颜色仅用于渲染，不写入正文样式，也不新增撤销记录。

代码块位于页面末尾时，点击其下方的正文空白区域会追加一个普通段落并聚焦，可直接继续输入；重复点击不会追加多余空块。此操作支持撤销与保存，代码块内 Enter 仍为块内换行。

## 块引用

点击目标块左侧「⋮⋮」→「复制块链接」，在同一页或其他页面的正文里粘贴，会显示为灰色段落图标和块内容摘要。单击引用会在当前标签页打开目标页面，滚动到对应块并短暂高亮；可用顶部后退按钮返回来源页。块引用文字取自粘贴时的块摘要，页面引用文字取自页面标题，跳转目标使用页面 ID 和稳定块 ID，不依赖文字、行号或滚动距离。

目标内容编辑、块移动、撤销／重做和重启后仍可定位。复制块会获得新的 ID，不会抢走原块的引用。目标被删除时会提示不存在，不跳到其他位置。复制链接前会保存目标块的 ID，旧笔记无需重新输入即可使用。代码块内粘贴和粘贴为纯文本保留链接原文。当前 `tree://page/页面ID#块ID` 链接由 Tree 正文内部处理。

[引用样式的原生渲染预览](docs/reference-style-preview.png) · [跳转高亮预览](docs/block-reference-target-preview.png)

块引用自动化测试覆盖菜单复制、原生粘贴和点击、长页面滚动定位、短暂高亮、保存重开、块移动／复制／删除／撤销、旧笔记 ID 持久化、无效目标，以及待办样式和代码内原文粘贴。

右上角「⋯」菜单提供「复制页面链接」。在正文粘贴后显示为页面名称，点击会在当前标签页打开对应页面，可通过顶部后退返回。页面链接不依赖正文块，空页面也可引用；重命名、保存重开后仍有效，页面删除后提示不存在，恢复后原链接可继续使用。

引用采用深色半粗文字、浅灰下划线和灰色行内图标：块引用显示段落图标与内容摘要，页面引用显示文档图标与标题。旧引用在打开笔记时更新样式，跳转目标与段落 ID 保留；图标不写入 Markdown / HTML 导出。

修复旧引用显式下划线向后续文字继承的问题：链接边界外继续输入不再带入下划线；打开笔记时清理普通标题中残留的下划线，保留真正链接及正文中主动设置的下划线。


## 页面图标

标题上方「添加图标」或右上角「⋯ → 设置页面图标」打开图标面板；已有图标可直接点击更换。支持中英文关键词搜索、按用途分组浏览、随机选择、移除、Enter 选择第一个搜索结果及 Esc 取消。使用彩色 SVG 原生绘制，图标与标题、正文共用滚动空间。

图标同步显示在侧栏、页面标题上方、面包屑、标签页、子页面入口、新标签页选择浮窗及正文内的页面引用中。图标 ID 保存在页面 JSON 元数据中，不改变正文或段落 ID；重启、回收站恢复和备份导入后保留。未知图标 ID 回退为默认文档图标。

资源采用 [Microsoft Fluent Emoji](https://github.com/microsoft/fluentui-emoji) 的 Flat 风格，精选 140 个彩色 SVG（约 325 KB），已下载到 `assets/page-icons/` 并嵌入应用，离线可用。原始 SVG 未修改，中文搜索词和分组由 Tree 添加。MIT 许可证随资源保存并嵌入应用；`SOURCE.json` 记录固定提交版本，`catalog.json` 记录原始路径及 SHA-256。运行 `python3 scripts/download_page_icons.py` 可重新下载并验证该版本的资源。

## Library

侧栏「Library」打开独立浏览页面，仅包含「最近访问」和「收藏」。列表展示页面图标与名称、来源（父页面，顶层页面显示“顶层页面”）、最后编辑时间，不设创建者列。点击名称打开页面，点击来源跳转到父页面，右上角可新建页面。

最近访问按本地访问时间倒序排列；收藏按收藏时间倒序排列。页面右上角星标、侧栏右键菜单和 Library 列表行的星标均可收藏／取消收藏。未收藏行的星标仅在悬停或键盘聚焦时显示。收藏保存在本地 settings 中，切换收藏不会修改正文、版本号或最后编辑时间；移入回收站的页面不显示，恢复后保留收藏状态。

Library 接入现有标签页历史，可后退、前进、切换标签及重启恢复，不会创建同名笔记。回归测试覆盖最近访问排序、未访问页面过滤、草稿保存、Library 导航与会话恢复、来源跳转、新建页面、收藏持久化与移除、回收站恢复、小窗口三列布局和相对时间显示。

## 计时待办

在正文输入 `/ttodo` 后按 Enter（或点击“计时待办”）创建。文字末尾的播放、暂停、勾选、叉号图标分别用于开始／继续、暂停、完成、废弃；图标与文字留 8 DIP 间距，24 DIP 点击区域之间留 2 DIP，换行时跟随最后一行。累计用时独立固定在最右侧，暂停期间不累计。完成后勾选待办，最右侧以淡色显示累计用时（分:秒，超过一小时为时:分:秒）；终止后正文加删除线。点击已完成／已终止项的复选框可回到暂停状态，随后继续计时。普通 Todo 保持原有行为。

开始或恢复计时后，每连续运行 20 分钟会询问“还在继续吗？”。应用在前台时显示带“在继续”按钮的通知；后台使用 macOS 系统通知，直接点击通知即可确认。5 秒内确认则不中断计时，并在确认 20 分钟后再次询问；未确认会自动暂停，等待确认的 5 秒计入本次用时。手动暂停、完成、废弃或删除任务会取消提醒，过期通知不能重新启动任务。

确认计时独立于页面显示，切换页面、滚动离开任务或收起 Leaf 后仍有效；多个计时任务分别确认。提醒截止时间保存在本地，休眠或重启后若已超时，按原截止时刻暂停，不累计额外无人确认的时间。系统通知需在 macOS 中允许 Tree 发送通知；拒绝通知不会阻塞超时暂停。


计时的开始、暂停、完成、终止会立即保存；界面刷新秒数不会反复写库或产生撤销步骤。切换页面、重启应用后，未超过确认截止时间的计时按保存的起点继续计算；超过时按截止时间暂停。回车产生的新计时块，以及复制／粘贴的计时块均从未开始状态计时，避免重复统计原任务的耗时。

每段实际计时保存开始／结束时刻、累计纳秒、所属本地日期、时区与 UTC 偏移。跨午夜的段落按本地日期拆分；暂停后的继续形成新段，不会把暂停间隔归入任何一天。正在运行的段可由保存的起点恢复。数据位于页面正文 JSON 的 `TaskTimes` 历史中，块内的 `Timer.HistoryID` 指向当前有效版本；`Body.taskTimeSegments` 返回当前有效记录并按日期补上正在运行的部分。统计时应通过该入口读取，不能直接累加所有历史版本。历史采用不可变版本以配合撤销／重做，完整数据包含在数据库与本地备份中。

计时回归测试另覆盖 20 分钟提醒、5 秒超时边界、迟到与重复确认、并行任务、后台页面及 Leaf、休眠／重启恢复；原有覆盖包括斜杠输入、按钮与复选框、暂停／继续、完成／终止、跨页与重启、块移动／复制／删除／撤销、长文本布局、按日拆分、暂停过夜、时区／夏令时边界及备份恢复。
